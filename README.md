# Assignment2-vechile-system

## Description
This project contains an abstract `Vehicle` class and its subclasses. 
It demonstrates the concepts of **inheritance** and **abstraction** in Java.

## Files
- `Vehicle.java` — abstract class definition
- Other subclasses (if any) implementing the Vehicle class

## How to Run
1. Compile the Java files using `javac *.java`
2. Run the main class using `java Main` (replace `Main` with your main class name)
